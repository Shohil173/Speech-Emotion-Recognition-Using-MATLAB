# Speech-Emotion-Recognition-Using-MATLAB
📌 Overview

This project implements a real-time Speech Emotion Recognition (SER) system using digital signal processing and machine learning. The system records live speech, extracts MFCC features, and predicts the speaker’s emotion using a K-Nearest Neighbour (KNN) classifier.

## 🎯 Emotions Detected

- Happy  
- Sad  
- Angry  
- Neutral

## ⚙️ Tools & Technologies

- MATLAB  
- Signal Processing Toolbox  
- Audio Toolbox  
- Statistics & Machine Learning Toolbox
## 🧠 Methodology

1. Record live speech using microphone  
2. Extract MFCC features from the audio signal  
3. Train KNN classifier using emotion dataset  
4. Predict emotion of the recorded speech
## 📊 Output

After recording, the system displays:

- Speech waveform  
- Spectrogram  
- MFCC feature plot  
- Predicted emotion
## ▶️ How to Run

1. Open MATLAB  
2. Set project folder as Current Directory  
3. Run:
   
emotion_recognition

Speak for a few seconds when prompted 🎤
